# OSRS Wiki

Unofficial phone reader for [oldschool.runescape.wiki](https://oldschool.runescape.wiki).

## Why

The OSRS Wiki is excellent on a desktop browser and awkward on a phone. This app is a dedicated reader: fast search, readable articles, offline pages, and an in-app world map — without fighting mobile Safari/Chrome chrome.

## Features

- **Search** — find pages quickly from a phone-sized UI
- **Read** — article layout tuned for small screens (light and dark)
- **Offline** — save pages to read without a connection
- **Map** — browse the Old School map in-app
- **Tips (Play builds)** — Google Play builds may offer optional in-app purchase tips; off-store tips use GitHub Sponsors when live (see Support)
